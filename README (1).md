# Родословно дърво

Самостоятелно уеб приложение за родословно дърво — всичко (HTML, CSS, JS)
е в един файл, данните се пазят в браузъра (localStorage), няма нужда от
сървър или база данни.

## Файлове в тази папка

- `index.html` — самото приложение (отваря се директно в браузър).
- `family-tree.manifest.json` — PWA manifest (име, икони, цветове).
- `family-tree-sw.js` — service worker за офлайн работа.
- `icon-192.png`, `icon-512.png` — икони за инсталиране на телефон/компютър.

Всичките файлове трябва да останат в една и съща папка — `index.html`
ги зарежда с относителни пътища.

## Как да го качиш в GitHub Pages (безплатно, с https адрес)

PWA инсталирането ("Добави на началния екран") изисква сайтът да е на
`https://` адрес — не работи от локален файл или от локална мрежа.
GitHub Pages дава такъв адрес безплатно.

1. Отиваш на [github.com](https://github.com) и влизаш в акаунта си
   (ако нямаш акаунт, го създаваш — безплатно е).
2. Горе вдясно → **+** → **New repository**.
   - Име: например `family-tree`.
   - Избираш **Public** (безплатният GitHub Pages изисква публично repo).
   - Не отбелязваш нищо друго (без README, без .gitignore) — Create repository.
3. На новата (празна) страница на repото търсиш линка
   **"uploading an existing file"** (или бутона **Add file → Upload files**).
4. Провлачваш и петте файла от тази папка (`index.html`,
   `family-tree.manifest.json`, `family-tree-sw.js`, `icon-192.png`,
   `icon-512.png`) и натискаш **Commit changes**.
5. Отиваш в **Settings** (горе в менюто на repото) → вляво **Pages**.
6. Под **Build and deployment → Source** избираш **Deploy from a branch**.
7. Под **Branch** избираш `main` и папка **/ (root)** → **Save**.
8. Изчакваш около 1 минута. Presz в горната част на Pages секцията ще се
   появи адрес от вида:

   `https://твоето-потребителско-име.github.io/family-tree/`

   Това е адресът на приложението ти — работи на всяко устройство.

## Как да го инсталираш на телефон

Отваряш адреса от стъпка 8 в браузъра на телефона.

**Android (Chrome):**
1. Натискаш менюто (трите точки ⋮) горе вдясно.
2. Избираш **"Инсталирай приложение"** или **"Add to Home screen"**.
3. Потвърждаваш — иконата се появява на началния екран като истинско приложение.

**iPhone / iPad (Safari):**
1. Натискаш бутона **Share** (квадратче със стрелка нагоре) долу в лентата.
2. Скролваш и избираш **"Add to Home Screen"**.
3. Потвърждаваш с **Add**.

> Забележка за iPhone: Safari може да изчисти запазените данни на сайта,
> ако не го отваряш дълго време. Затова е добре периодично да ползваш
> бутона **"Запази във файл"** в приложението като резервно копие.

## Инсталиране на компютър

Отваряш същия адрес в Chrome или Edge на компютъра → в адресната лента
се появява иконка за инсталиране (⊕ или монитор с стрелка) → натискаш я →
**Install**. Приложението се отваря в собствен прозорец, без адресна лента.

## Обновяване на приложението по-късно

Ако промениш `index.html` (или другите файлове) отново:
1. Отиваш в repото в GitHub.
2. Отваряш файла → иконката на молив (Edit) → нанасяш промените → Commit changes.
   (Или изтриваш стария файл и качваш новия през Add file → Upload files.)
3. GitHub Pages се обновява автоматично за секунди — при следващо отваряне
   на приложението (или презареждане) промените се виждат.
